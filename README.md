# スワヒリ語 動詞の分解・組み立て

スワヒリ語の動詞を、主語・時・目的語・語根・語尾に分けて色分け表示するツールです。ボタンを選んで、1語を組み立てることもできます。

🌐 **https://gengootakulab-star.github.io/swahili-words/**

[言語オタクの多言語学習ラボ](https://gengootakulab-star.github.io/) のツールの1つです。

## できること

- **分解する**: 動詞を入力すると、部品に分けて表示します(例: `ninakupenda` → `ni-na-ku-pend-a`「私はあなたを愛している」)。ブロックをタップすると説明が出ます。切り方が何通りもある語は、候補を並べます。
- **組み立てる**: 「だれが・肯定/否定・いつ・だれを・どうする」をボタンで選ぶと、動詞ができあがります。
- URLの末尾に `?w=単語` を付けると、その語を分解した状態で開きます。

## 対応している形

現在・過去・未来・完了などの基本の時制、否定、不定詞(ku-)、習慣(hu-)、接続法、命令、「持っている」(nina など)。
関係節(〜する人、など)と、いくつかの不規則な形には対応していません。

## 注意事項

- 分解の結果と日本語の訳は、規則から機械的に作った目安です。誤りが含まれる可能性があります。
- 誤りを見つけたときは、ページ下部の「誤りを報告する」(フォーム、アカウント不要)か、このリポジトリの Issue で教えてください。

## データの出典

- 辞書データ: [Wiktionary](https://en.wiktionary.org/)(CC BY-SA 4.0)。[kaikki.org](https://kaikki.org/dictionary/Swahili/) が公開する抽出データを、加工して利用しています。
- 日本語の訳は、運営者がAIの助けを借りて作成したものです。
- 分解と組み立ての規則は、Wiktionary の活用表(約3,100語分)と照合して確認しています。

## 構成

`index.html` 1ファイルに、画面・プログラム・辞書データがすべて入っています(ビルド不要)。調べた語の履歴は、ブラウザの中(localStorage)だけに保存します。閲覧数は、Cookieを使わない [GoatCounter](https://www.goatcounter.com/) で集計しています。
